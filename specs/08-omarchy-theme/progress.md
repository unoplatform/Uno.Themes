# Omarchy theme (`Uno.Omarchy.WinUI`)

A fourth design-system library, ported from
[flutter_omarchy](https://github.com/aloisdeniel/flutter_omarchy) (vendored under
`artifacts/flutter_omarchy/`, MIT). Terminal-inspired: one monospace face, sharp corners,
2 px borders, translucent "tint" fills, an accent stroke for focus/selection, and an
8-color ANSI palette (normal + bright) on top of background/foreground/accent/selection/muted.

Source of truth for every value below: `packages/flutter_omarchy/lib/src/theme/*.dart`
(palette model + 21 stock palettes) and `lib/src/widgets/*.dart` (per-widget state colors).

## Design

### Color model (mirrors `OmarchyColorThemeData`)

`OmarchyPalette` (C# record): `Background`, `Foreground`, `Accent`, `Selection`, `Muted`,
`Normal`/`Bright` (`OmarchyAnsiPalette`: Black, White, Red, Green, Yellow, Blue, Magenta, Cyan),
`IsLight`. The legacy `border`/`selectedText` fields of the Dart class are aliases of `accent`
in the current `colors.toml` format and are not carried over. `OmarchyPalettes` holds the 21
stock palettes generated from `fallback.g.dart` (default: `TokyoNight`, as in the source).

**One palette, both theme dictionaries.** Omarchy has a single active palette with a
light/dark *flag*; it does not have a light and a dark variant. `OmarchyTheme.Palette`
therefore feeds identical values into the `Light` and `Default` theme dictionaries. Apps that
want to follow the system theme switch palettes (e.g. `CatppuccinLatte` for light).

**Runtime palette switching** (the `omarchy theme set` experience) works like the seed-color
stack: the palette dictionary passed to `BaseTheme` as the base color override is a single
instance that is re-populated in place, `UpdateSource()` rewrites the shared semantic brushes,
and the Omarchy-specific brushes are stable `SolidColorBrush` instances whose `Color` is
rewritten (see `specs/lessons.md`, "StaticResource in a Source-loaded ResourceDictionary").

### Resource keys

Colors (per palette, in `Light` + `Default`):
`OmarchyBackgroundColor`, `OmarchyForegroundColor`, `OmarchyAccentColor`,
`OmarchySelectionColor`, `OmarchyMutedColor`,
`OmarchyNormal{Black,White,Red,Green,Yellow,Blue,Magenta,Cyan}Color`,
`OmarchyBright{...}Color`. Brushes: same names with `Brush` (opaque, stable instances).

Semantic role mapping (the shared `*Color`/`*Brush` layer):

| Role | Omarchy | Role | Omarchy |
|---|---|---|---|
| Primary | Accent | OnPrimary | Background |
| PrimaryContainer | Accent @15% over Background | OnPrimaryContainer | Accent |
| PrimaryInverse / PrimaryVariantDark / PrimaryVariantLight | Accent | | |
| Secondary | Normal.Magenta | OnSecondary | Background |
| SecondaryContainer | Magenta @15% over Background | OnSecondaryContainer | Bright.Magenta |
| SecondaryVariantDark / Light | Normal.Magenta / Bright.Magenta | | |
| Tertiary | Normal.Cyan | OnTertiary | Background |
| TertiaryContainer | Cyan @15% over Background | OnTertiaryContainer | Bright.Cyan |
| Error | Normal.Red | OnError | Background |
| ErrorContainer | Red @15% over Background | OnErrorContainer | Bright.Red |
| Background / Surface | Background | OnBackground / OnSurface | Foreground |
| SurfaceVariant | Normal.Black (`lighter_background`) | OnSurfaceVariant | Muted |
| SurfaceInverse | Foreground | OnSurfaceInverse | Background |
| SurfaceTint | Accent | Outline | Normal.White |
| OutlineVariant | Normal.Black | | |

"@15% over Background" is the alpha-composited *solid* color of the Omarchy filled tint, so
container roles look like Omarchy's filled widgets while staying opaque.

them: sharp corners are the identity of the theme.

### Templates: tint layers, not per-state brushes

Omarchy derives hover/pressed/disabled from **one** color per role and an alpha. Instead of a
`*Background`/`*BackgroundPointerOver`/`*BackgroundPressed` key set per style (which would need
a template copy per ANSI accent - 8 colors x 3 button kinds), Omarchy templates layer a
`Border` fed by `{TemplateBinding Background}` whose `Opacity` the visual states drive from the
tokens above, and a focus/pressed `Border` fed by `{TemplateBinding Foreground}`. An accent
variant is then three setters (`Background` = normal color, `Foreground` = bright color,
`BorderBrush` = normal color). Lightweight styling keeps the base keys (`FilledButtonBackground`,
`FilledButtonForeground`, `FilledButtonBorderBrush`, ...); the `*PointerOver`/`*Pressed` state keys
of the other themes do not exist here - documented in `doc/omarchy-controls-styles.md`.

### Typography

Bundled `CaskaydiaMono Nerd Font Mono` (Regular / Bold / Italic, as the source package
bundles them). Omarchy has one size (14) and three faces; the type scale is:

| Slot | Face | Sizes (L/M/S) |
|---|---|---|
| Display | Bold | 32 / 28 / 24 |
| Headline | Bold | 20 / 18 / 16 |
| Title | Bold | 16 / 14 / 14 |
| Body | Regular | 14 / 14 / 12 |
| Label | Regular | 14 / 12 / 12 (ExtraSmall 11) |
| Caption | Italic | 12 / 12 / 11 |

`TypefacePlain` / `TypefaceBrand` = Regular. Sizes above 14 are an extension (Omarchy only
uses 14 and 12); faces per slot follow the source (`bold` for titles, `italic` for
descriptions/hints, `normal` for everything else).
