### Placeholder

Once an item is selected, the Material ComboBox keeps its placeholder visible as a floating label: a scaled-down copy shown above the selected value. These keys apply to the Material style only:

- `ComboBoxUpperPlaceHolderScaleX`, `ComboBoxUpperPlaceHolderScaleY` and `ComboBoxUpperPlaceHolderTranslateY` size and position the floating label.
- `ComboBoxUpperPlaceHolderMargin` offsets the floating label within the field. The label is centered in the same area as the selected value, so this moves the label only; the selected value keeps its fixed offset below it.
- `ComboBoxPlaceholderTextStyle` is the text style of both the placeholder and the floating label. It must target `TextBlock`. The template sets `Foreground` on both and `Margin` on the floating label, so those setters in this style have no effect; use the `ComboBoxPlaceHolderForeground*`, `ComboBoxUpperPlaceHolderForeground*` and `ComboBoxUpperPlaceHolderMargin` keys instead.

> [!NOTE]
> On Uno Platform targets, the `ScaleX`, `ScaleY` and `TranslateY` keys are looked up again from the application resources when the app theme changes at runtime. Overrides declared in `App.xaml` are kept, but overrides declared on a page or on the ComboBox itself revert to the defaults after a theme change. The `Margin` and text-style keys are not affected. See [unoplatform/uno#24958](https://github.com/unoplatform/uno/issues/24958).

```xml
<ComboBox PlaceholderText="Label">
    <ComboBox.Resources>
        <x:Double x:Key="ComboBoxUpperPlaceHolderScaleX">0.6</x:Double>
        <x:Double x:Key="ComboBoxUpperPlaceHolderScaleY">0.6</x:Double>
        <x:Double x:Key="ComboBoxUpperPlaceHolderTranslateY">-13</x:Double>
        <Thickness x:Key="ComboBoxUpperPlaceHolderMargin">0,0,0,2</Thickness>
        <StaticResource x:Key="ComboBoxPlaceholderTextStyle" ResourceKey="BodyMedium" />
    </ComboBox.Resources>
</ComboBox>
```
