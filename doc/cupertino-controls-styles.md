## Buttons

Apple's buttons answer to interaction by dimming rather than by changing color, so every Cupertino button shares one template: pointer-over, pressed and disabled only change the opacity of the whole control. A variant is a foreground and a background.

| Style | Semantic key | Look |
| ----- | ------------ | ---- |
| `CupertinoPlainButtonStyle` | `TextButtonStyle`, implicit `Button` | Accent text, no background. Apple's default button. `CupertinoButtonStyle` is its previous name. |
| `CupertinoProminentButtonStyle` | `FilledButtonStyle` | Accent capsule, white text. `CupertinoContainedButtonStyle` is its previous name. |
| `CupertinoTintedButtonStyle` | `FilledTonalButtonStyle` | Pale accent capsule, accent text. |
| `CupertinoGrayButtonStyle` | `OutlinedButtonStyle`, `ElevatedButtonStyle` | Gray capsule, accent text. Apple has neither an outlined nor an elevated button; this is the closest to both. |
| `CupertinoDestructiveButtonStyle` | | Plain, in the error color. |
| `CupertinoGlassButtonStyle` | | A [Liquid Glass](xref:Uno.Themes.Cupertino.GetStarted#liquid-glass) capsule. |
| `CupertinoGlassProminentButtonStyle` | | Glass tinted with the accent, white text. |
| `CupertinoIconButtonStyle` | `IconButtonStyle` | A 44 px circle around the content, accent glyph, no background. |
| `CupertinoGlassProminentIconButtonStyle` | `FabStyle`, `SmallFabStyle` (`LargeFabStyle` is the 56 px `CupertinoLarge…` style) | Accent glass circle. The HIG has no floating action button; a floating control is where Apple uses glass. |
| `CupertinoGlassIconButtonStyle` | `SecondaryFabStyle`, `SecondarySmallFabStyle`, `SecondaryLargeFabStyle` (large) | Glass circle. |
| `CupertinoTintedIconButtonStyle` | `TertiaryFabStyle`, `TertiarySmallFabStyle`, `TertiaryLargeFabStyle` (large) | Pale accent circle. |
| `CupertinoGrayIconButtonStyle` | `SurfaceFabStyle`, `SurfaceSmallFabStyle`, `SurfaceLargeFabStyle` (large) | Gray circle. |

> [!IMPORTANT]
> The glass styles are opt-in. A glass surface repaints on every frame, so keep glass for the few buttons that float above content, and use the other styles in forms and lists. No semantic button key other than the FAB family resolves to glass.

Set `ut:ControlExtensions.Icon` (`xmlns:ut="using:Uno.Themes"`) to show an icon before the content.

## Toggle buttons and links

`CupertinoTextToggleButtonStyle` (`TextToggleButtonStyle`, and the implicit `ToggleButton`) is a gray capsule that takes the accent tint when checked. `CupertinoIconToggleButtonStyle` (`IconToggleButtonStyle`) is the same toggle as a 44 px circle and reads the same keys. `CupertinoHyperlinkButtonStyle` (`HyperlinkButtonStyle`) is accent text; `CupertinoSecondaryHyperlinkButtonStyle` (`SecondaryHyperlinkButtonStyle`) uses the secondary label color. As with the buttons, the interaction states dim the control and have no keys of their own.

| Key | Default |
| --- | ------- |
| `TextToggleButtonForeground` / `TextToggleButtonBackground` | `OnSurfaceBrush` / `SecondaryContainerBrush` |
| `TextToggleButtonForegroundChecked` / `TextToggleButtonBackgroundChecked` | `PrimaryBrush` / `PrimaryContainerBrush` |
| `HyperlinkButtonForeground` | `PrimaryBrush` |
| `SecondaryHyperlinkButtonForeground` | `OnSurfaceVariantBrush` |

## Text fields

`CupertinoTextBoxStyle` and `CupertinoPasswordBoxStyle` (`OutlinedTextBoxStyle`, `OutlinedPasswordBoxStyle`, and the implicit styles) draw a hairline border. `CupertinoFilledTextBoxStyle` and `CupertinoFilledPasswordBoxStyle` (`FilledTextBoxStyle`, `FilledPasswordBoxStyle`) have no border and sit on the gray fill, the look of a search field or of a field inside a grouped list.

| Key | Default |
| --- | ------- |
| `FilledTextBoxForeground` / `FilledTextBoxBackground` / `FilledTextBoxPlaceholderForeground` | `OnSurfaceBrush` / `SecondaryContainerBrush` / `OnSurfaceVariantBrush` |
| `FilledPasswordBoxForeground` / `FilledPasswordBoxBackground` | `OnSurfaceBrush` / `SecondaryContainerBrush` |
| `CupertinoFilledTextBoxCornerRadius` | `10` (both filled styles) |

## Progress bar and ring

`CupertinoProgressRingStyle` (`ProgressRingStyle`, and the implicit style) is Apple's activity indicator: eight spokes, 20 px, turning one spoke every 0.1 s. `CupertinoLargeProgressRingStyle` is the 37 px size. The HIG has no determinate activity indicator, so a determinate ring shows the spokes at rest; use a `ProgressBar` to show progress. On WinAppSDK the native ring is kept and tinted.

| Key | Default |
| --- | ------- |
| `CupertinoProgressRingSize` / `CupertinoLargeProgressRingSize` | `20` / `37` |

`CupertinoProgressBarStyle` (`ProgressBarStyle`, and the implicit style) is a 4 px rounded bar. It stretches to the width it is given, with a minimum of 250 px.

| Key | Default |
| --- | ------- |
| `ProgressBarForeground` / `ProgressBarBackground` | `PrimaryBrush` / `OutlineVariantBrush` |
| `CupertinoProgressBarHeight` / `CupertinoProgressBarMinWidth` / `CupertinoProgressBarCornerRadius` | `4` / `250` / `2` |

## Lists

`CupertinoListViewStyle` (`ListViewStyle`, and the implicit `ListView`) is an inset-grouped list: the list itself is the group, a surface with a 26 px rounded corner, and `CupertinoListViewItemStyle` (`ListViewItemStyle`, the implicit `ListViewItem`) is a 44 px row with a hairline separator inset 16 px from the leading edge. A row highlights with the gray fill while hovered or pressed, takes the selection tint when selected and dims when disabled. Give the list a `Margin` to inset the group from the edges of the page; a list is content, so it has no glass.

| Key | Default |
| --- | ------- |
| `ListViewBackground` / `ListViewBorderBrush` | `SurfaceBrush` / `OutlineVariantBrush` |
| `ListViewItemForeground` | `OnSurfaceBrush` |
| `ListViewItemBackgroundPointerOver` / `ListViewItemBackgroundPressed` | `SecondaryContainerBrush` |
| `ListViewItemBackgroundSelected` | `PrimarySelectedBrush` |
| `ListViewItemSeparatorBrush` | `OutlineVariantBrush` |

| Key | Default | Description |
| --- | ------- | ----------- |
| `CupertinoRowMinHeight` / `CupertinoRowPadding` | `44` / `16,0` | |

## Alerts

`CupertinoContentDialogStyle` (`ContentDialogStyle`, and the implicit `ContentDialog`) is an alert: a title, a message and full-width 44 px action rows separated by hairlines, on `Thick` [Liquid Glass](xref:Uno.Themes.Cupertino.GetStarted#liquid-glass) over a dimming layer. The rows stack primary, secondary, then close (Cancel) at the bottom; the `DefaultButton` is bold. Set `PrimaryButtonStyle` (or another button style) to `CupertinoContentDialogDestructiveButtonStyle` for an action in the error color; `CupertinoContentDialogButtonStyle` and `CupertinoContentDialogDefaultButtonStyle` are the plain and bold rows.

| Key | Default |

| `ContentDialogForeground` | `OnSurfaceBrush` |
| `ContentDialogSeparatorBrush` | `OutlineVariantBrush` |
| `CupertinoDialogTintBrush` | The surface color at 80 % opacity, laid over the glass |
| `CupertinoDimmingBrush` | `#59000000`, the layer behind the alert |

| Key | Default | Description |
| --- | ------- | ----------- |

## Popovers and menus

`CupertinoFlyoutPresenterStyle` (`FlyoutPresenterStyle`, and the implicit `FlyoutPresenter`) is a popover: its content sits on a `Thick` [Liquid Glass](xref:Uno.Themes.Cupertino.GetStarted#liquid-glass) panel behind a hairline, in a 26 px rounded corner, with 16 px of padding. `CupertinoMenuFlyoutPresenterStyle` (`MenuFlyoutPresenterStyle`) is the same surface, at least 250 px wide, holding 44 px rows: `CupertinoMenuFlyoutItemStyle`, `CupertinoToggleMenuFlyoutItemStyle`, `CupertinoRadioMenuFlyoutItemStyle`, `CupertinoMenuFlyoutSubItemStyle` and `CupertinoMenuFlyoutSeparatorStyle` (their semantic keys, and the implicit styles). A row highlights with the gray fill while hovered or pressed and dims when disabled; an icon leads the label, a checked toggle or radio row shows a leading checkmark, a sub-item a trailing chevron, and a separator is a hairline inside an 8 px band. The `ComboBox` popup is the same glass menu. `CupertinoToolTipStyle` (the implicit `ToolTip`) is the macOS tooltip: caption text on the surface, behind a hairline, solid rather than glass.

## Navigation and command bars

`NavigationViewStyle` and `NavigationViewItemStyle` use the stock navigation behavior with a solid surface pane, 44 px minimum rows and 10 px row corners. Selection uses `PrimarySelectedBrush` with `PrimaryBrush` text; hover and pressed backgrounds use `SecondaryContainerBrush`. Both left and top navigation are supported.

`CommandBarStyle` keeps the stock command layout and overflow behavior on a solid surface. Its compact height is 44 px. `AppBarButtonStyle` uses a 22 px icon with a minimum 44 by 44 px target; compact commands hide their labels, while overflow commands show labels beside icons, keyboard shortcuts and submenu indicators. Hover, press and disabled states dim the command. Glass behind the navigation pane and command groups is deferred.

## Page indicators and ratings

`PipsPagerStyle` uses 7 px dots in 16 px boxes, with `OnSurfaceLowBrush` for unselected pages and `OnSurfaceBrush` for the selected page. The reusable `CupertinoPipsPagerNormalPipStyle` and `CupertinoPipsPagerSelectedPipStyle` can also be assigned to the pager's corresponding style properties.

`RatingControlStyle` retains the stock rating glyphs and interaction, with 16 px glyphs in Uno's stock 32 px layout. Selected stars use `PrimaryBrush`; unselected stars use `SecondaryBrush`. Caption, hover and disabled colors follow semantic brushes.

## Field and calendar color overrides

Field borders share `CupertinoFieldBorderBrush`, painted from `LabelColor` at opacity 0.2. The existing `CupertinoTextBoxBorderBrush`, `CupertinoPasswordBoxBorderBrush`, `CupertinoComboBoxBorderBrush`, `CupertinoDatePickerBorderBrush` and `CupertinoDeleteButtonTextBoxBrush` keys remain available. Number-box header and detail brushes retain their 0.7 and 0.3 opacities. Calendar selection follows the primary seed at opacity 0.27; an explicit `CupertinoBlueColor` override takes precedence.

Use the theme's `Colors.OverrideDictionary` to override color keys. These brushes repaint in place when overrides or seeds change, and clearing the override restores the palette. See [color overrides](cupertino-getting-started.md) and [lightweight styling](lightweight-styling.md).
